# PHP Multiplication Table

A small PHP page that prints the 12 times table.

## Features

- Prints 12 x 1 to 12 x 10 with a PHP `while` loop
- Simple styled HTML heading

## Tech stack

PHP, HTML

## Getting started

```bash
git clone https://github.com/Matiz009/php-multiplication-table.git
cd php-multiplication-table
php -S localhost:8000
# open http://localhost:8000/alpha.php
```
